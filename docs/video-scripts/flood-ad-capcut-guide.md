## ✂️ CapCut 剪辑步骤

### Step 1: 导入素材
1. 打开 CapCut → 新建项目 → 竖屏 9:16 (1080×1920)
2. 导入 `D:/HTH/photo/` 中的 3 张主图

### Step 2: 时间线布局
| 轨道 | 时间段 | 内容 |
|------|--------|------|
| 视频轨 | 0:00-0:03 | 鱼特写（Scene 1） |
| 视频轨 | 0:03-0:08 | 池塘全景（Scene 2） |
| 视频轨 | 0:08-0:12 | 大鱼抢食（Scene 3） |
| 视频轨 | 0:12-0:15 | 标志+CTA（Scene 4） |
| 字幕轨 | 全程 | 泰语字幕 + 中文翻译 |
| 音效轨 | 按场景 | 警报/泡泡/金币/叮 |
| BGM轨 | 全程 | 轻快泰国风音乐 |

### Step 3: 特效添加
- **Scene 1**：暴雨粒子 + 警报闪烁 + 眼睛放大贴纸
- **Scene 2**：泡泡动画 + 「海景房」便签贴纸 + 水波纹
- **Scene 3**：「暴击」文字特效 + 箭头跳动 + 发光边框
- **Scene 4**：爱心跳动 + Logo 淡入

### Step 4: 配音录制
1. 使用 CapCut「文本转语音」功能
2. 选择泰语语音（如无法找到，用真人配音后同步）
3. 调整语速：稍快（1.1x）增加紧迫感

### Step 5: 导出设置
- 分辨率：1080×1920
- 帧率：30fps
- 码率：推荐 15-20 Mbps
- 格式：MP4 (H.264)
