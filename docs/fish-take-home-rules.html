01先说结论

你系统里已经在跑的规则是：渔获前 1 公斤免费，超出部分 60฿/公斤， 离场前由员工逐次称重计入订单，每笔可备注鱼种。

我的判断：这个骨架是对的——它和 BO SANG（称重后可带走）、 日本钓堀（免费额度 + 超出每 100g）、深圳青青世界（场地费 + 按斤买走）是同一个模型。

所以缺的不是算法，是一本顾客看得懂的规则书。难点也不在价格， 而在「哪些鱼能带走、哪些必须放回」——这一条几乎每家泰国鱼塘都会单独写出来。

三条规律

① 大鱼塘一律禁止带走，家庭休闲塘才开放带走——你属于后者，所以「可带走」是卖点，不该藏起来。
② 凡开放带走的，一定有「不能带走」清单（保住种鱼与设备投资）。清单是规则书的核心，不是附注。
③ 渔获价贴着市价走：曼谷罗非鱼 80–90฿/kg、鲶鱼 65฿/kg — 你的 60฿/kg 是略低于市价，当「带走奖励」讲得通，也有涨价余地。

03建议规则（逐条增减）

A基本规则 建议保留
A1入场费包含钓位、1 根竿与基础饵料，时段内不限竿数（按你实际：是否限竿、含不含饵）
A2渔获前 1 公斤免费带走现规则。同类里这是很划算的额度（日本只给 500g），值得显眼地讲
A3超出部分 60฿/公斤，离场前统一称重价格可否上调 / 分档，待你定
A4渔获费与餐费同单结算，前台一次付清系统已支持
B能带 / 不能带 核心条款 内容待你确认
B1可带走：有鳞鱼（ปลาเกล็ด）—— 罗非鱼（尼罗/红）、鲮鱼、鳙/鲢、草鱼…请补全塘里实际有的鱼种
B2不可带走（必须放回）：超过 ? kg 的大鱼 / 种鱼亲鱼 / 名贵观赏鱼建议照 BO SANG：官网单列一页，配图 + 三语名
B3不可带走的鱼，由员工现场放回，客人可先拍照明确「谁放回」，避免客人把鱼抱走
B4客人可自愿放回任何鱼，放回的不称重、不计费给「纯钓鱼」的客人一条路
C称重与结算 建议保留
C1只称要带走的鱼；放回的不称能大幅减少称重次数与客诉
C2称重点设在塘边固定位置，员工当着客人面称，客人可看秤这一条能省掉绝大多数「称重不信任」的争执
C3可分次称重，累计到同一张单系统已有「称重记录」+ 逐笔备注鱼种
C4渔获费不参与任何折扣学深圳青青世界。否则员工可用折扣额度把鱼「送」出去
C5称重单上写明鱼种与重量，客人离场前签字确认可选；留下凭证
D竞赛塘怎么算（500฿/人/天，10 人起） 三选一，待你定
D1严格竞赛：渔获全部放回，只称总重排名，渔获不计费 最接近 BO SANG 与泰国竞赛塘的通行做法。推荐——竞赛塘的鱼是「比赛道具」，反复使用才摊得平成本
D2宽松：按总重排名，同时允许带走（前 1kg 免费 / 超出 60฿/kg）客人体验好，但竞赛塘消耗快
D3团队打包价：整场按团队包干，渔获全部带走适合企业团建、比赛后聚餐
E附加服务（可增收） 可选，建议先挑 1–2 条
E1代客杀鱼、去鳞、去内脏：? ฿/条 或 ฿/公斤日本钓堀多作为免费服务；泰国现场加工常见 100–200฿/公斤
E2提供冰块 / 泡沫箱打包：? ฿泰国天热，不冰的鱼带回家会腥——这条容易收费也容易得好评
E3现场餐厅代加工（清蒸 / 油炸 / 烤）：菜品价 + 加工费你有菜单，这条能把渔获直接变成餐厅营收
E4竿租用 150฿ / 自带竿 100฿已上线
F护鱼与设施规则 可选，建议至少采纳 F1
F1拍照不超过 3 分钟；不许抠鳃；不许把鱼抛入水，要轻放进水照抄 BO SANG 的 Fish Care Guide，是同类里写得最清楚的
F2必须使用无倒刺钩Leks 等高端场强制；休闲塘可只做「建议」
F3竿损坏 / 遗失赔偿：? ฿Leks 丢竿 8,000฿、断竿 4,000฿；EFT 丢竿 6,000฿
F4禁止外带食物饮料Leks 明确禁止；你有餐饮与钓具，这条保护营收

04需要你补充的信息

  1. 塘里主要有哪些鱼？各归「可带走 / 不可带走」哪一类？（截图或手写都行，我照着做成三语鱼种卡）
  2. 除了有鳞鱼，还有哪些鱼？
  3. 「大鱼」的界重量是多少 kg？（超过就必须放回）
  4. 竞赛塘三个选项（D1 / D2 / D3）你选哪个？
  5. 有代杀鱼 / 冰块打包 / 餐厅代加工吗？各收多少？
  6. 竿损坏或遗失，要不要写赔偿条款？多少฿？
  7. 允许客人自带食物饮料吗？
  8. 儿童怎么收费？（几岁免票 / 半价）
