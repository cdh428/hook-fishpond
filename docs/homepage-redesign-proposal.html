首页改版提案 · v1 · 待讨论

让首页看起来值得专程去一趟

对照 Hook Happyness 的社交阵地与泰国同类鱼塘的线上打法，问题不在功能，而在首页没有"卖相"—— 没有实景、没有社会认同、没有把"大鱼 / 美食 / 好去处"讲清楚。下面是改版后的首页设计稿，确认方向后再落代码。

先看清现状

三条结论决定了改版该往哪使劲。

你的社交阵地

Facebook Hookhappyness、LINE @300bsham 都是登录墙后的封闭页面，我无法直接读取内容。

  • 站内 LINE 机器人只用来给管理员发日报
  • 前台没有任何 FB / LINE / 电话 / 地图入口
  • 顾客想找你，只能靠搜索

泰国同类怎么打

看了 BO SANG（清迈）、Krabi Fishing Park、Palm Tree Lagoon、Bungsamran 等官网与点评页，共性非常一致：

  • 首屏必给 3 个大数字：鱼重 / 塘口面积 / 营业时间
  • "可带鱼回家"是泰国人最在意的卖点，单独放大
  • 照片即信任：钓获、餐食、钓台，全是实拍
  • 餐饮是独立吸引点（Coffee Fish 开成单独官网）

你的首页缺什么

现有首页只有渐变、图标和四行功能说明，整体像"功能目录"，不像"目的地"。

  • ❌ 没有一张实景照片
  • ❌ 没有评分、评价、钓获等社会认同
  • ❌ 没有地址、时间、电话、地图
  • ❌ 没有把"大鱼"和"美食"讲成卖点

1

顶部栏加 LINE / 电话入口

顾客最常用的两个动作（问路、问有没有位）现在一步可达，不再藏在页面底部。

2

Hero 换成实景大图 + 情绪主张

从"欢迎来到乐钓鱼塘"改成"放下手机，来钓一条大鱼"。首屏一张好照片 + 一句话，胜过十行功能说明。

3

双 CTA：预约 + LINE 咨询

泰国人习惯先 LINE 问一句再决定。给一条低门槛路径，能多接住一批犹豫的客人。

4

新增数据条（社会认同）

20+ 鱼种 / 2 个塘口 / 06–22 营业——泰国同类官网的标配，三秒建立"这是个正经场地"的认知。

5

塘口卡加实拍 + 权益清单

现在只有图标和一行描述。改成照片 + 价格 + 三条具体好处，顾客一眼知道 100฿ 买的是什么。

6

新增"为什么选我们"四宫格

大鱼 / 美食 / 遮阳钓台 / 可带鱼回家。"可带鱼回家"是泰国人心里的硬指标，BO SANG 直接拿它当标题。

7

新增钓获实拍墙

横向滑动的真实钓获，标上重量。这是最有说服力的广告，而且素材就在你手机里。

8

新增钓友评价

把 Google / 脸书上的好评搬上首页。示例文案上线前会换成真实评价。

9

新增位置 · 时间 · 导航

地址、营业时间、地图、"导航前往"。同类站点都有，你现在完全没有——这是最直接的客流损失。

10

新增社交关注区

Facebook Hookhappyness + LINE @300bsham 正式挂上首页，把网站流量导回你的社交池。

需要你确认的几件事

把这几项补齐，我就能把设计稿落成真实代码。

① 实拍照片

Hero 一张、塘口两张、大鱼/餐食/钓台/带鱼回家各一张、钓获 4–8 张。手机拍的就行。

② 地址与地图

泰文地址 + Google Maps 链接，用于"导航前往"。

③ 电话与营业时间

客服电话；是否全年无休、有无固定休息日。

④ 真实评价

从 Google / 脸书挑 2–3 条好评（含昵称），或授权我按真实评论整理。

⑤ "可带鱼回家"规则

哪些鱼可以带走、有没有限制？这是最值得放大的卖点。

⑥ 首屏主张

"放下手机，来钓一条大鱼"是否合你口味？也可以换成更朴实的版本。
