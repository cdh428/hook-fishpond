## 零、开门前（约 5 分钟）

1. 收银机的浏览器打开 **https://hookfishpond.com/zh/admin**，用**店长给的账号**登录。
   （登录一次之后，在后台里跨页面不用反复登。）
2. 进 **打印设置** → 点**打测试页**。
   - 出纸、字清楚 → 可以开始营业。
   - 不出纸 / 泰文是乱码 → 见 §七 排错。
3. 回到**仪表盘**，看一眼「待收款」有没有**昨天遗留**的订单。
4. 如果今天是**泰国法定节假日**（周一固定休息之外想加休），
   去 **休息日** 页把日期加上 —— 否则顾客会照常下预约。

> ⚠️ **周一固定休息**，系统硬性拦住，不需要手动操作。

## 一、顾客下单之后

订单的状态是这五步，在**订单看板**里按顺序点：

```
待处理 → 制作中 → 已出餐 → 已上桌 → 已结账
```

| 状态 | 什么时候点 |
|---|---|
| 待处理 | 顾客刚下单，自动进这个状态 |
| 制作中 | 后厨开始做（点这个会**同时出后厨单**） |
| 已出餐 | 菜做好了 |
| 已上桌 | 送到客人桌上 |
| 已结账 | 钱收完了 |

订单可以被**取消**（进入「已取消」）。取消会**自动把占用的库存还回去**，不用手工处理。

### 几种常见的单子

- **堂食**：必须选桌号。客人扫桌上的二维码（`/t/<桌号>`）进来，桌号会自动带上。
- **打包**：不带桌号，默认先付款（见 §四）。
- **顾客在座位上按「呼叫服务员」**：订单看板会有提示，过去看一下就行。

## 二、称重与渔获费（最容易算错的一步）

客人要**把鱼带走**时：

1. 在订单里点**称重**，把整条的重量录进去（有几条录几条）。
2. 系统自动算渔获费：
   - **所有鱼种**合计，**首 1 公斤免费**
   - 超出部分 **60 ฿/公斤**
   - **例外**：`ปลาบึก`（湄公巨鲶）**不分大小必须放回塘里**，不能带走
3. 客人要**代加工**（清蒸 / 油炸 / 烤）→ 每条约 **100 ฿**，**和渔获费分开算**。

> ⚠️ **称鱼的时候当面把鱼竿收回来。** 竿没交回，**先不要结账**
> —— 这是器材损坏/丢失（统一赔 1,000 ฿）唯一的抓手。

## 三、折扣

- 店员可以打折，**上限 10%**。
- 超过 10% 系统会**直接拒绝**，提示需要管理员。
  → 这种情况**叫店长来操作**，不要想办法绕过。

---

## 四、结账

两种结算方式：

| 方式 | 默认用在 | 说明 |
|---|---|---|
| **先付款** | 打包 | 下单时就要付 |
| **后付款** | 堂食 | 吃完一起结 |

- 顾客用 **PromptPay 扫二维码**付款时，二维码**15 分钟**就失效；
  超时了让顾客重新生成即可。
- **钱到账了再点「已结账」**（系统看不到银行到账，这一步是人工确认）。

---

## 五、菜单与库存

### 菜单
- 菜品和分类都在 **菜单** 页维护；可以**跨大类移动**（美食 / 饮品 / 钓具）。
- 批量改可以**导出 CSV → 改 → 导入**。
- 想临时下架某个菜 → 关掉它的「上架」开关（**顾客立刻看不到**）。

### 库存
库存是**三个动作**，别搞混：

| 动作 | 什么时候用 |
|---|---|
| **入库** | 进货到了（采购单） |
| **调整** | 实际数和账上对不上 —— **盘点**时用 |
| **损耗** | 坏了 / 洒了 / 自己人吃了 |

- **卖出去不用你手动扣**：下单时系统**先占住**，结账时**才真正扣掉**。
- 系统里看到的「可用数」已经扣掉了被订单占住的部分，直接按它报数就行。
- 卖完了想标**售罄**，在库存页点售罄。

## 六、每天收工前

1. 订单看板筛选「**待结账**」→ 确认**没有漏结**的堂食单。
2. **收款**页核对一遍今天的收款记录。
3. **报表**页看一眼今天的营业额（想导 Excel 就点导出）。
4. 打印机的纸够不够 —— 不够就换。

> 系统每天 **21:00（泰国时间）会自动把经营日报推到 LINE**，
> 所以第二天早上也能在 LINE 里看到前一天的数字。

---

## 七、排错

| 现象 | 怎么办 |
|---|---|
| 打印不出纸 | 先看**打印设置**页的「检测状态」；USB 机看有没有脱机，蓝牙机看有没有开机且连上 |
| 泰文打得是乱码 | 走的是位图光栅，一般不会；若出现，**重新打测试页**确认，然后叫技术人员 |
| 后台登录不上 | 确认账号没输错。**连续输错会被临时锁 15 分钟**，等一下再试 |
| 页面转圈很久 | 数据库在海外，**首次打开慢是正常的**（可能十几秒）；先等，别反复刷新 |
| 顾客说看不到某个菜 | 检查该菜品的**上架开关**，以及它所属**分类**的开关 —— **两个都开**才可见 |
| 订单金额不对 | 别手改！看有没有**称重没录**或**折扣没加**；仍不对就叫技术 |

## 八、每周 / 每月

**每周**
- 做一次**库存盘点**，差异用「调整」录入并写清楚原因。
- 看一眼**热销**和**毛利**报表 —— **菜品没录成本价的话毛利是空的**，记得让店长补录。

**每月**
- 核对休息日设置对不对（尤其法定节假日）。
- 检查外网地图/评价平台上的**地址和电话是否一致**（不一致会影响客人找到店）。
- 让店长确认一下管理员口令是否需要更换。

---

## 九、哪些事你**不要**自己决定

- 超过 10% 的折扣 → 叫店长。
- 器材损坏 / 丢失的赔偿 → 按 1,000 ฿ 的统一标准，**特殊情况叫店长**。
- 菜品价格、规则文案的改动 → 走店长，别在后台自己改文案。
- 任何「改代码 / 改网站」的事 → 交给技术。
