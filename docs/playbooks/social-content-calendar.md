## 二、发布节奏（泰国时区 GMT+7）

| 时段 | 用途 |
|---|---|
| **周四 / 周五 18:00–20:00** | 主推时段 —— 刷到的人正好安排周末，转化最好 |
| **周六 09:00** | 当天到店提醒（"今天开门"） |

## 四、Metricool 操作要点

1. **Planning（排期）** → 选日期时间 → 选账号（可一次多选 FB + IG + TikTok）
2. 视频：**TikTok 和 Reels 只用竖版**（`promo-9x16.mp4` / `fishpond-flood-ad-v2.mp4`）
3. 图片：**只用 `.jpg`**，`.webp` IG 会失败
4. Media library 里先上传一次，之后排期直接选，省得每次填 URL
5. 时区确认是 **Bangkok (GMT+7)** —— Metricool 设置里检查，否则发布时间全错
6. 发完看 **Analytics** → 哪条 reach 高，下个月照着那个形式多做

## 五、LINE 缺口（Metricool 补不上）

Metricool 只管"发帖"，管不了"发消息"。下面三件事它都做不了：

| 需求 | Metricool | 建议方案 |
|---|---|---|
| 顾客私信/评论统一回复 | ❌ | SleekFlow / respond.io 免费版试 |
| 主动广播（活动通知） | ❌ | 同上（LINE 广播只有这类工具能做） |
| 内部日报 / 库存告警 | ❌ | **Telegram Bot**（5 分钟拿 token、免费不限量，改造量最小） |

⚠️ 前提不变：**任何工具连 LINE，都需要 LINE 官方账号 + Messaging API 渠道可用**。
若 @300bsham 已无法登录，LINE 这条线就是断了，只能靠 FB/IG/TikTok + Telegram。
