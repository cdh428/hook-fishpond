# Hook Fishpond 专用打印机工作站 (USB + Tailscale 远程打印部署包)

本目录为专用打印机工作站的自包含运行包。
插好 USB 的 POS80 打印机后，可直接在该电脑上运行。

---

## 包含文件清单

1. **`启动打印服务.bat`**：**【一键运行】** 自动配置防火墙规则、测试 POS80 出纸并启动服务。
2. **`config.json`**：纯 USB 配置文件（已预设 `defaultPrinter: "POS80"`，杜绝蓝牙串口干扰）。
3. **`bridge.py`**：核心服务程序（已固化 400px 黄金安全宽度、泰中双语分行排版、末尾 1 行留白切纸）。
4. **`escpos.py`**：GDI 高清图像与 USB 驱动通信模块。
5. **`render.py`**：无头 Chromium 渲染引擎。
6. **`HookFishpond-PrintBridge.vbs`**：开机静默启动脚本（无黑框）。

---

## 目标机（desktop-h9c31c4）部署 3 步走

### 步骤 1：拷贝文件
将本文件夹（`tools/print-bridge`）整体拷贝到目标电脑任意位置（如 `D:\print-bridge` 或 `C:\print-bridge`）。

### 步骤 2：一键启动与测试
在目标电脑上鼠标右键点击 **`启动打印服务.bat`** -> 选择 **「以管理员身份运行」**：
1. 脚本会自动在 Windows 防火墙中放行 `17777` 端口；
2. 自动调用系统的 USB `POS80` 驱动打出一张自检纸（确认 USB 硬件工作正常）；
3. 自动以 `0.0.0.0` 模式启动监听，同时支持本机、局域网以及 Tailscale（`100.85.92.120:17777`）跨网远程调用！

---

## 安全通信秘钥（Auth Key）设置（可选）

如果您希望为跨网打印增加安全防护：
1. 打开 `config.json`，在 `"authToken"` 中填入一个密码（例如 `"HookSecret2026"`）；
2. 在网站后台（Admin 打印设置页）的「通信访问密钥」中输入同样的密码点击保存即可；
3. 未携带此密钥的网络请求将被直接 401 拦截。
