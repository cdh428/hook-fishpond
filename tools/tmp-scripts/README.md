# 临时脚本 / 一次性产物：不入库，用完即可删

本文件（`.gitignore` 生效）用来标记**一次性调试脚本**，避免它们散落在 `scripts/` 里被误当成正式工具。

## 判定标准

**正式工具**（该保留、该有 README、该进 `scripts/`）：
- 会被反复执行（推送、检查、迁移、扫描影响面）
- 别人照文档就能跑
- 有确定性输出

**一次性脚本**（放这里，或直接删）：
- 只为某一次排查写的（查某张订单、算某天的账、验证某个 URL 通不通）
- 硬编码了某张订单号 / 某个员工的用户名
- 跑完就再也不会跑第二次

## 本目录现有内容

| 文件 | 用途 | 可删？ |
|---|---|---|
| `state-check.cjs` | 查「未结清订单 + 已付/流水」现状 | 保留，排障常用 |
| `migrate-run.cjs` | 执行 `prisma/migrations/*/migration.sql` | 保留，幂等迁移用 |
| `i18n-add.py` | 批量往三语 JSON 追加同名 key | 保留，加文案常用 |

新增一次性脚本请**直接放这里**，别丢 `scripts/`；跑完随手删掉，或在此表登记一行。
